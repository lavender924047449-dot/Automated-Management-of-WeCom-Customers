# Test-Voice GUI 使用手册

## 1. 启动与首启

1. 运行 `python -m gui.main`（或双击 GUI 可执行文件）。
2. 首次启动若提示“尚未初始化”，点击“是”并按提示输入账号标识（建议使用 `vid`）。
3. 初始化完成后，顶部“当前账号”下拉会出现该账号，五个页面会自动切换到该账号的数据。

## 2. 顶部账号栏

- **当前账号**：切换后，素材库、编辑和发送消息、@和群公告发布、执行结果都会热重载。
- **刷新**：重新扫描本地账号目录。
- **初始化新账号**：创建新账号数据空间，并将当前上下文切换到新账号。

## 3. 联系人页

- 子页签：全部、外部客户、外部群、内部同事。
- 支持按备注名搜索。
- 点击标签可批量勾选联系人，勾选结果会同步到“编 Plan”页。

## 4. 素材库页

- 支持按类型过滤：`voice/text/image/video/oa/link`。
- 支持按名称、标签搜索。
- 右侧详情区支持预览（语音/图片/视频/文本/OA/link）。
- “待命名 N 条”可一键定位未命名素材。

## 5. 编 Plan 页

1. 选择联系人。
2. 添加素材步骤并拖拽排序。
3. 设置消息间隔、联系人间隔与语音扰动开关。
4. 选择发送时间：
   - 立即执行
   - N 时间后
   - 具体时刻
   - 循环（每天/每周）
5. 点击“开始执行”或“提交调度”。

> 定时任务到点会弹出 60 秒确认框，点击“立即开始”才会执行。

## 6. @和群公告发布

1. 左侧只列出「编辑和发送消息」里的外部群，可搜索、勾选、确认。
2. 右侧填写群公告。勾选「@所有人」后，可再写一条文字；执行时先发群公告，再发这条 @所有人。
3. 下方调度与「编辑和发送消息」相同：群聊间隔、立即执行 / N 时间后 / 具体时刻 / 循环。
4. 执行结果进入「执行结果」页。

## 7. 执行结果页

- 顶部可选日期，格式 `yyyy年M月d日`；仅展示该日期的「正在执行计划」和「当日待执行计划」。
- 顶部按钮：`立即停止/接续开始`、`重新发送此轮任务`、`重试所有失败项`、`简略视图`。
- 右上角小框展示循环计划（可双击看详情，也可右键删除）。
- 发送列表按计划→联系人→消息层级显示，状态支持 `30%/70%/发送成功/发送失败/已暂停`。
- 失败消息支持行内“重新发送”；本轮仍在发送时，补发会排队到本轮结束后执行。
- 双击消息可打开素材预览；双击待执行/循环计划标题可打开计划详情。

## 8. 帮助菜单

- **使用手册**：打开本文件。
- **检查更新**：联网检查公开的 GitHub Releases。目录分发包有新版本时，下载更新包，只覆盖「程序」，然后重新打开。联系人、素材、计划和 vendor 不会被替换。
- **关于**：查看当前版本、企微适配版本和 GitHub 链接。

## 9. 托盘与退出

- 直接关闭窗口会最小化到系统托盘，定时任务继续运行。
- 需要完全退出时，使用：
  - 菜单“文件 → 完全退出”，或
  - 托盘右键“完全退出”，或
  - 快捷键 `Ctrl+Q`。

## 10. 常见问题

- **看不到账号**：点击“刷新”；确认 `data/<account_id>/` 目录存在。
- **素材无法预览**：检查素材文件是否仍在原路径，或重新拉取素材。
- **没有弹更新提示**：先在“帮助 → 检查更新”手动触发；离线状态下不会提示。发布附件名需要是 `program-update.zip`。
- **点了更新没有自动覆盖**：需要用「启动.exe」打开目录分发包。开发环境和单个 exe 只会打开发布页。
