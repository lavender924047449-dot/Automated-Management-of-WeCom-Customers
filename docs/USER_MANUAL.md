# Test-Voice GUI 使用手册

## 1. 启动与首启

1. 运行 `python -m gui.main`（或双击 GUI 可执行文件）。
2. 首次启动若提示“尚未初始化”，点击“是”并按提示输入账号标识（建议使用 `vid`）。
3. 初始化完成后，顶部“当前账号”下拉会出现该账号，四个页面会自动切换到该账号的数据。

## 2. 顶部账号栏

- **当前账号**：切换后，联系人/素材库/编 Plan/执行结果都会热重载。
- **刷新**：重新扫描本地账号目录。
- **初始化新账号**：创建新账号数据空间，并将当前上下文切换到新账号。

## 3. 联系人页

- 子页签：全部、外部客户、外部群、内部同事。
- 支持按备注名搜索。
- 点击标签可批量勾选联系人，勾选结果会同步到“编 Plan”页。

## 4. 素材库页

- 支持按类型过滤：`voice/text/image/video/oa/link`。
- 支持按名称、标签搜索。
- 右侧详情区支持预览（语音/图片/视频/文本/OA/link）。
- “待命名 N 条”可一键定位未命名素材。

## 5. 编 Plan 页

1. 选择联系人。
2. 添加素材步骤并拖拽排序。
3. 设置消息间隔、联系人间隔与语音扰动开关。
4. 选择发送时间：
   - 立即执行
   - N 时间后
   - 具体时刻
   - 循环（每天/每周）
5. 点击“开始执行”或“提交调度”。

> 定时任务到点会弹出 60 秒确认框，点击“立即开始”才会执行。

## 6. 执行结果页

- 顶部显示当前任务进度。
- 主表格显示逐条发送状态（成功/进行中/失败）。
- 可“重试失败项”。
- 可“导出 CSV”用于复盘与归档。

## 7. 帮助菜单

- **使用手册**：打开本文件。
- **检查更新**：检查 GitHub Releases 最新版本。
- **关于**：查看当前版本、企微适配版本和 GitHub 链接。

## 8. 托盘与退出

- 直接关闭窗口会最小化到系统托盘，定时任务继续运行。
- 需要完全退出时，使用：
  - 菜单“文件 → 完全退出”，或
  - 托盘右键“完全退出”，或
  - 快捷键 `Ctrl+Q`。

## 9. 常见问题

- **看不到账号**：点击“刷新”；确认 `data/<account_id>/` 目录存在。
- **素材无法预览**：检查素材文件是否仍在原路径，或重新拉取素材。
- **没有弹更新提示**：先在“帮助 → 检查更新”手动触发；离线状态下不会提示。
