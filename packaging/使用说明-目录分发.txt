这是目录分发包，四个部分在同一层：

1. 启动.exe    固定入口，很少更换
2. python\     内嵌 Python 和依赖。依赖没变就不要换
3. 程序\       界面和发送代码。更新时只覆盖这一层
4. data\ 与 vendor\
   data 是联系人、素材、计划。vendor 是 adb 和 frida-server。更新程序时不要覆盖这两处。

双击 启动.exe 打开。
以后更新：在程序里点「帮助 → 检查更新」，确认后会下载更新包，只覆盖「程序」和版本号，然后重新打开。
也可以手动用新的「程序」文件夹覆盖旧的，再重新打开。
更新时不要覆盖 data 和 vendor。
